# Jupiter Layers

A browser view of Jupiter you can peel. The outer shell is the cloud deck, with the belts and the Great Red Spot. Under it: molecular hydrogen, liquid metallic hydrogen, the dilute core from the Juno mission, and a small denser center drawn as a hypothesis.

English and Traditional Chinese. Open the FAQ for the short answers, including why a Starship cannot land.

## Run

```bash
npm install
npm run dev
```

Then open the app on port 8080.

## Notes

The planet is a stylized Three.js model, not a photograph and not a numerical interior model. Sizes of the inner shells are exaggerated so each layer stays visible.
